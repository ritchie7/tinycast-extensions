# Tinycast Xcode Projects

在 Tinycast 里搜索最近使用的 Xcode 工程、工作区、Swift 包和 Playground。

## 安装

在 Tinycast 打开 **Settings → Extensions → Install New → Install from GitHub**，输入 `https://github.com/ritchie7/tinycast-extensions/tree/main/extensions/xcode-projects`。在项目列表按 **⌘K → Check for Updates** 可比较已安装版本和仓库版本。发现新版后确认复制链接并打开设置，再从 GitHub 重新安装。

## 使用

运行 **Search Recent Projects**。按项目名或目录搜索，也可以在右侧筛选项目类型。

- **↩** 用 Xcode 打开项目。
- **⌘↩** 在 Finder 中显示并选中项目文件。
- **⌘⇧F** 收藏或取消收藏。
- **⌘R** 刷新索引。

在扩展设置中填写扫描目录，多个目录用英文冒号分隔。收藏排在最前，其余结果结合 Spotlight 的使用日期、Xcode 工作区状态文件时间以及通过此扩展打开项目的时间排序。搜索时优先匹配项目名称。扫描目录、项目索引和收藏保存在本机。
