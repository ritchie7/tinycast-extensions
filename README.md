# Tinycast Extensions

每个扩展独立安装。在 Tinycast 打开 **Settings → Extensions → Install New → Install from GitHub**，粘贴所需扩展的目录链接。更新时使用同一链接重新安装。

| 扩展 | 用途 | 安装地址 |
| --- | --- | --- |
| Xcode Projects | 搜索最近使用的 Xcode 工程、工作区和 Swift 包 | [extensions/xcode-projects](https://github.com/ritchie7/tinycast-extensions/tree/main/extensions/xcode-projects) |
